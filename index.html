01 · 适用范围

本政策适用于由个人开发者 MaoWeiye 提供的乒乓拍档（PingDuo）iPhone/iPad 应用，应用标识为 com.weiye.pingduo。

视频解码、球追踪、动作识别、回合编辑和导出均在设备本地完成。开发者不提供应用后台、云端视频处理或云端同步服务，应用不向开发者上传视频、识别结果、使用记录或诊断信息。

02 · 本地视频与数据

只有你主动选择的视频会被导入。应用保存所选视频的副本、缩略图、分析检查点、球轨迹与回合结果，用于播放、编辑和导出；不会自动扫描或导入整个照片图库。

以下资料保存在设备上：

  • 视频标题、拍摄日期、你填写的对手标签，以及回合边界、收藏、排除状态和集锦选择。
  • 语言、显示模式、回合时间，以及用于本地回合排序的观看和曝光记录。
  • 分析任务进度、恢复检查点、错误状态和照片保存回执。
  • 本机免费分析的成功次数和处理中的额度记录。免费次数仅限本机，不跨设备共享。

这些内容不会用于广告，也不会自动发送给开发者。模型随应用提供，分析不需要把素材传到远程服务。

03 · 系统权限

权限或功能用途与选择
照片选择与读取导入你主动选择的视频；读取其原始标题和拍摄日期；在保存中断后核对成片，避免重复保存。拒绝读取权限后，仍可通过系统选择器导入，并使用文件中的信息。
添加到照片仅在你导出或保存成片时请求，用于把视频写入系统照片图库。
Apple 登录可选。本机只保存 Apple 提供的登录标识；应用不向开发者发送身份令牌、姓名或邮箱。退出登录不重置本机免费次数。
App Store 订阅购买、恢复和交易验证使用 Apple StoreKit。Apple 处理交易，应用在设备端验证订阅权益；开发者不接收支付卡资料，也不建立交易验证后台。

你可在系统设置中调整照片权限。关闭权限不会自动删除已导入的应用内视频副本。

04 · Apple 崩溃报告与 TestFlight

应用没有自建自动诊断上传、诊断接口或第三方崩溃收集 SDK。正式版崩溃报告使用 Apple 官方渠道，由 Apple 根据系统共享设置管理；你可在 设置 → 隐私与安全性 → 分析与改进 中调整相关选项。

如你参加 TestFlight 测试，Apple 会按其规则处理测试安装和使用资料，并自动向开发者共享崩溃报告，不受正式版系统共享开关限制。你主动发送 Beta 反馈时，Apple 会提供你提交的文字、截图和相关诊断。截图可能包含视频画面或个人信息，请在发送前检查。

Apple 的收集、保留及删除规则见 Apple 隐私政策和 TestFlight 与隐私说明。开发者不会另行把这些报告上传至自建服务。

05 · 保留、删除与撤回

项目和分析资料保留在设备上，直到你删除相应项目或移除应用。删除项目会移除应用管理的源视频副本和相关分析资料，不会删除系统照片中的原始视频。对手标签和全局偏好可能继续保留。导出的成片由照片应用管理，需在照片中自行删除。

本机免费次数和可选 Apple 登录标识保存在设备 Keychain 中；免费次数不会因退出登录重置。Keychain 项目可能在卸载后继续保留，设备迁移和系统行为会影响其可用性，因此我们不承诺卸载可重置免费次数，也不承诺跨设备累计。退出登录会移除应用保存的登录标识；Apple 授权关系可在系统 Apple 账户设置中管理。

系统备份与恢复由你的设备设置及 Apple 服务管理，应用不提供单独的云端备份。开发者无法读取或远程删除你设备上的项目。

你主动发送邮件或反馈时，开发者仅为回应请求、排查故障和必要后续使用你提供的资料，并在无需继续保留时删除。你可通过下方邮箱请求访问、更正或删除开发者能够控制的资料；Apple、GitHub 或邮箱服务提供方管理的数据按各自政策处理。

06 · 隐私政策网站

本网站只用于展示隐私政策和联系方式，托管于 GitHub Pages。没有广告、访问统计、跟踪脚本、第三方字体或数据填写表单；不是应用的视频处理、账号、额度或诊断服务。

GitHub 可能为提供和保护网站处理 IP 地址及访问请求日志。参阅 GitHub 隐私声明。点击联系邮箱会打开你的邮件应用，只有你主动发送邮件后，开发者才会收到邮件内容。
