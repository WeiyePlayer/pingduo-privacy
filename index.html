01 · 适用范围

乒乓拍档（英文名 PingDuo）是由 Weiye 开发的 iPhone/iPad 乒乓球视频分析应用，应用标识为 com.weiye.pingduo。

本政策适用于当前的 TestFlight 本地功能测试版本。本轮测试无需登录或订阅，分析不限次数，未启用账户、订阅、远程额度或应用服务器诊断服务。

如果后续版本启用账户、付费订阅、云端服务或新的数据处理方式，我们会在启用前更新本政策和相关应用说明。

02 · 本地视频与数据

你主动选择的视频会被复制到应用管理的本地存储，用于解码、设备端 Core ML 分析、回合播放和导出。应用不会自动扫描或导入整个照片图库。

为提供这些功能，应用会在设备上保存：

  • 所选视频的副本、缩略图、分析检查点与识别结果。
  • 视频标题、日期、你填写的对手标签，以及回合边界、收藏和排除状态。
  • 回合时间、显示模式等偏好，以及用于本地回合排序的观看与曝光记录。
  • 排查故障所需的本地错误码、版本和任务状态。

当前测试版本不会向开发者的应用服务器上传源视频、视频画面、分析结果、对手标签或上述本地记录。应用未接入广告或第三方行为分析 SDK，也不利用这些信息进行跨应用跟踪。

03 · 系统权限

权限或入口用途与选择
系统照片选择器由你选择要导入的视频，应用只取得你选择的内容。
照片读取权限用于读取所选视频的原始标题与拍摄日期。拒绝后仍可导入，并使用文件中可取得的信息。
保存到照片在导出时，将你选择生成的回合或集锦保存到系统照片。

你可以在 iOS/iPadOS 的“设置”中调整权限。拒绝保存权限会影响保存到照片的功能。当前版本不请求摄像头、麦克风、联系人或位置权限。

04 · TestFlight 与反馈

TestFlight 由 Apple 提供。测试期间，Apple 会收集安装与使用情况、设备和系统信息、崩溃日志，并向开发者提供测试信息。通过邮箱邀请参加测试时，开发者也可看到邀请邮箱、姓名（如有）和邀请状态。

你主动提交反馈时，Apple 会向开发者提供你的文字说明、截图及相关诊断信息。截图可能包含视频画面、标题或其他个人信息；请在发送前检查内容，避免包含你不希望分享的信息。

开发者仅将这些测试资料用于处理反馈、排查问题和改进 PingDuo，不出售这些资料，也不将 TestFlight 测试资料分享给第三方。当前应用自己的诊断记录只保存在设备本地，不向应用服务器发送。

Apple 的收集方式和保留期限受其政策约束。请阅读 Apple 的 TestFlight 与隐私说明。

05 · 保留与删除

本地项目数据会保留到你删除项目或移除应用。删除应用中的视频项目，会移除该项目的应用内视频副本及相关分析资料；不会删除系统照片中的原始视频。

对手标签和全局偏好可能在项目删除后继续保留。导出到系统照片的成片由照片应用独立管理，需要在照片中自行删除。卸载应用会移除应用沙盒数据；根据你的设备设置，系统备份或恢复可能保留或恢复部分应用数据。

开发者仅在处理测试反馈和改进软件所需期间使用反馈资料。你可以通过下方联系渠道请求访问、更正或删除开发者能够控制的个人信息。Apple 管理的 TestFlight 数据按 Apple 的保留与删除规则处理。

06 · 网站与第三方

本隐私政策网站托管于 GitHub Pages。网站未添加广告、访问统计、跟踪脚本或数据填写表单。GitHub 作为托管服务提供方，可能处理访问网站所需的 IP 地址和请求日志等信息；详情请参阅 GitHub 隐私声明。

应用在设备上的存储和系统备份受你的 Apple 设备设置控制。Apple TestFlight、系统照片和 GitHub 的相关服务分别受其自身政策约束。
